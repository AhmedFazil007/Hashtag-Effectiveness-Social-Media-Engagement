# 📊 Hashtag Effectiveness in Boosting Social Media Engagement

## 📌 Project Overview
This project analyzes the effectiveness of hashtags in enhancing social media engagement. It evaluates how content source, format, and emotional tone influence user interactions such as likes, shares, and comments.

## 🎯 Objectives
- Analyze the impact of hashtags on engagement.
- Identify key drivers influencing social media performance.
- Provide data-driven marketing recommendations.

## 📈 Key Insights
- Influencer-led and visually rich content generated higher engagement.
- Emotional and humorous hashtags significantly improved user interaction.
- Strategic hashtag usage enhanced brand visibility and recall.

## 🛠️ Tools and Technologies
- Microsoft Excel
- SPSS
- Google Forms
- Data Visualization Techniques

## 📊 Dataset
- Survey responses from 340 participants.
